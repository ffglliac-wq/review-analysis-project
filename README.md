# review-analysis-project
# Анализ отзывов клиентов Amazon

## О проекте
Анализ 1177 отзывов клиентов Amazon для выявления проблемных товаров и паттернов недовольства клиентов.

## Технологии
- Python 3.14.7
- Pandas (обработка данных)
- Matplotlib (визуализация)
- Регулярные выражения (очистка текста)
- 
## 📊 Данные
**Источник:** [Amazon Product Reviews Dataset](https://www.kaggle.com/datasets/yasserh/amazon-product-reviews-dataset)
**Описание:** Датасет содержит отзывы клиентов Amazon о различных товарах.
**Размер:** 1597 отзывов, 27 колонок

**Как скачать:**
1. Перейдите по ссылке выше
2. Нажмите кнопку "Download"
3. Разархивируйте файл в папку проекта
4. Файл должен называться `amazon_reviews.csv`

## Что было сделано
1. **Очистка данных** - удалены пропуски, исправлены типы данных
2. **Ценовой анализ** - выявлена связь между ценой и удовлетворённостью
3. **Анализ текста** - найдены частые проблемы через биграммы
4. **Анализ по товарам** - выявлены топ-10 проблемных продуктов

## Ключевые выводы
- Дешёвые товары ($15-30) ломаются быстро → "waste of money"
- Дорогие товары не оправдывают ожиданий клиентов
- Главная проблема — ненадёжность, а не цена
- Alexa Voice Remote требует замены каждые 3-6 месяцев
